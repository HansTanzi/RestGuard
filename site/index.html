Built to make breaks happen

Breaks that actually happen

A 10-minute break after every 60 minutes of work, on every monitor. Alt+F4 does nothing, and you can't quit from the tray mid-break.

Highly customizable

Start a custom profile from any level and tune postpones, skipping, urgent mode, coverage and dragging. Keep as many as you like.

Stays out of the way

Waits while Zoom, Teams, Webex or Tencent Meeting is in use, and pauses the countdown when you're away from the keyboard.

Never miss the end of a break

A sound plays when the break is over, and ntfy can push it to your phone and smartwatch, so you know when to come back.

Small and fast

Rust + Tauri 2 on the system WebView. Downloads are just 2.5 ~ 4.6 MB and it barely uses any resources in the background.

Speaks your language

13 UI languages, following the system by default. Switch any time from the tray menu.

Install

Package managers keep RestGuard up to date. Direct downloads are portable and don't update on their own.

WinGet

winget install HansTanzi.RestGuard

Scoop

scoop bucket add hanstanzi https://github.com/HansTanzi/scoop-bucket
scoop install hanstanzi/restguard

Direct download

A portable single exe with no installer: put it anywhere and delete it to uninstall. Requires the WebView2 runtime (preinstalled on Windows 11).

Homebrew

brew install --cask hanstanzi/tap/restguard

Direct download

Universal build for Apple Silicon and Intel. Unzip and move RestGuard.app to /Applications. The app isn't notarized, so clear the quarantine flag before first launch:

xattr -dr com.apple.quarantine /Applications/RestGuard.app

Debian / Ubuntu (APT repository)

sudo install -d /etc/apt/keyrings
curl -fsSL https://hanstanzi.github.io/apt/hanstanzi.gpg | sudo tee /etc/apt/keyrings/hanstanzi.gpg > /dev/null
echo "deb [signed-by=/etc/apt/keyrings/hanstanzi.gpg] https://hanstanzi.github.io/apt stable main" | sudo tee /etc/apt/sources.list.d/hanstanzi.list
sudo apt update && sudo apt install rest-guard

Direct download

sudo dnf install ./RestGuard_*_x86_64.rpm            # Fedora
sudo zypper install ./RestGuard_*_x86_64.rpm         # openSUSE
sudo pacman -U ./RestGuard_*_x86_64.pkg.tar.zst      # Arch

x86_64 only. The overlay needs X11. Homebrew on Linux is supported too, see the README.

Verify your download

Release files are built by GitHub Actions with a signed build provenance attestation. Check one with the GitHub CLI:

gh attestation verify RestGuard_<version>_x64.exe --repo HansTanzi/RestGuard

Or compare against SHA256SUMS.txt from the Release:

sha256sum -c SHA256SUMS.txt --ignore-missing          # Linux
shasum -a 256 -c SHA256SUMS.txt --ignore-missing      # macOS
Get-FileHash .\RestGuard_*_x64.exe                    # Windows
